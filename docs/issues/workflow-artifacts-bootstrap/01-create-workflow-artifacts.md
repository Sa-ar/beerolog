# Create workflow artifact structure

## What to build

Create the durable local workflow artifact structure required by the bootstrap PRD: `CONTEXT.md`, ADR docs, PRD conventions, issue-slice conventions, and the feature-specific issue folder.

## Acceptance criteria

- `CONTEXT.md` exists at the repo root
- `docs/adr/README.md` exists
- `docs/prds/README.md` exists
- `docs/issues/README.md` exists
- `docs/issues/workflow-artifacts-bootstrap/` exists with numbered slice docs
- The roadmap plan remains unchanged

## Blocked by

None

## Notes

Keep the structure minimal, durable, and local-first.
